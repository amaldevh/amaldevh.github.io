Correct dynamic handling of 0-D tensors in torch.compile

Diagnosed a TorchDynamo graph-caching bug that incorrectly treated scalar tensor values as compile-time constants. Implemented a tensor-aware decomposition and regression tests, restoring correct dynamic behaviour.
